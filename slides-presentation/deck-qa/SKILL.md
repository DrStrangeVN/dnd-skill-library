# Deck QA

Run this after a deck is built or when the user asks for a presentation review.

## QA passes

### 1. Content integrity
- Numbers match the source.
- Units, dates, currencies and periods are consistent.
- Forecasts are labeled.
- Claims are supported.
- No placeholder text remains.

### 2. Storyline
- The deck has a clear beginning, evidence path and ending.
- Slide order is logical.
- Each slide has one dominant message.
- Executive summary matches the body.
- The requested call-to-action or decision is visible.

### 3. Visual quality
- Titles and body text are readable.
- Elements align to a consistent grid.
- No accidental overlaps, clipping or tiny labels.
- Charts use sensible scales and labels.
- Tables are not denser than necessary.
- Repeated slide chrome is consistent.

### 4. Delivery readiness
- File is editable when requested.
- Links and sources work when included.
- Confidential notes are not unintentionally exposed.
- Speaker notes are included only when requested.

## Output

For review-only requests, report issues by severity: Critical, Important, Polish. For creation workflows, fix issues directly when possible and mention only material unresolved items.

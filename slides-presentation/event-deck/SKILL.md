# Event Deck

Turn an event brief into a presentation covering concept, experience, operations, media, timeline and resources.

## Workflow
1. Identify objective, audience, venue, timing, format, budget constraints, brand requirements and success metrics.
2. Develop a clear event concept and experience journey.
3. Separate creative concept from operational execution.
4. Map guest/customer journey when relevant.
5. Show zones, program flow, production, content capture and staffing at the right level.
6. Include risks, dependencies and contingency planning for operational decks.

## Default structure
Cover; Brief/objective; Big idea; Audience; Experience journey; Key zones/touchpoints; Program/run-of-show; Production requirements; Branding/content; Promotion plan; Timeline; Budget summary; KPI/measurement; Next step.

# Brand System

Create or apply a reusable visual language for Presentation Pro decks.

## Priority order

1. Explicit user instructions.
2. Supplied brand guideline or native template.
3. Supplied reference deck/design.
4. Saved brand profile in supporting files.
5. Presentation Pro defaults.

## Workflow

1. Extract confirmed brand elements: logo, palette, typefaces, spacing, imagery, icon style, chart styling and tone.
2. Distinguish confirmed brand rules from inferred styling.
3. Define slide roles: cover, section divider, content, data, comparison, timeline, quote, closing.
4. Keep typography and spacing consistent across the deck.
5. Apply accessible contrast and legible type sizes.
6. Keep brand decoration subordinate to content.
7. When brand assets are missing, use a restrained neutral system and label it as a proposed style rather than an official brand identity.

## Default visual principles

- 16:9 layout unless instructed otherwise.
- Strong title hierarchy.
- Limited type scale.
- Consistent margins and alignment grid.
- One accent color plus neutrals unless the brand requires more.
- Charts use the brand accent for emphasis and muted tones for context.
- Use real supplied imagery when available; avoid generic decoration that adds no meaning.

Read `references/brand-profile.md` when a reusable brand profile is needed.

# Report Deck

Turn raw reporting material into a concise decision-ready presentation.

## Workflow
1. Identify audience, reporting period, business objective, and decision needed.
2. Read all supplied source material before structuring the deck.
3. Separate facts, calculated metrics, assumptions, and recommendations.
4. Build the storyline before designing slides.
5. Prioritize trend, variance, target-vs-actual, drivers, risks, and next actions.
6. Use charts for comparisons or trends; use tables only when exact values matter.
7. Surface 3-5 executive takeaways near the beginning.
8. End with actions, owners, timing, or decisions required.

## Default structure
Cover; Executive summary; KPI snapshot; Performance overview; Key drivers; Detailed analysis; Risks/issues; Opportunities; Action plan; Appendix.

## Rules
- Write slide titles as conclusions when possible.
- Keep body copy short.
- Show units and reporting periods consistently.
- Never fabricate missing numbers.
- When asked for a finished deck, create an editable PowerPoint.

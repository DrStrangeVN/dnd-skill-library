# 1. MỤC TIÊU

Xây dựng một plugin chuyên biến dữ liệu kinh doanh, vận hành, tài chính, sales, marketing, project, HR, event hoặc team performance thành một hệ thống KPI và báo cáo hiệu suất hoàn chỉnh.

Người dùng có thể chỉ nhập:

> Phân tích KPI tháng này giúp tôi.

Hoặc:

> Đây là file sales tháng 8, làm dashboard.

Hoặc:

> Tôi muốn đánh giá performance team marketing quý này.

Hoặc:

> Làm báo cáo KPI cho BOD.

Plugin phải tự:

- Hiểu dữ liệu
- Xác định KPI quan trọng
- Làm sạch dữ liệu nếu cần
- Tính KPI
- So sánh target
- So sánh kỳ trước
- Phân tích trend
- Tìm bất thường
- Tìm root cause
- Xác định risk
- Đề xuất corrective action
- Gán owner
- Đề xuất deadline
- Xây dashboard
- Xuất báo cáo premium

Output có thể là:

### XLSX Dashboard

hoặc:

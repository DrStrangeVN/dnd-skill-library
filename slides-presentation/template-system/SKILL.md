# Template System

Use a template as a visual and structural accelerator, not as a reason to force content into unsuitable slots.

## Presets

Read `references/presets.md` and choose the closest preset based on audience and purpose.

## Selection rules

1. Native user-provided templates always take priority.
2. Match template to audience: Board/Executive, Client/Partner, Sponsor, Event, Investor, Internal Operations.
3. Match information density: concise executive vs detailed working deck.
4. Match visual tone only after purpose is clear.
5. Never change factual content merely to fit a preset.

## Template behavior

- Preserve a supplied template's masters, layouts, typography and recurring geometry where possible.
- Reuse layouts consistently rather than creating a new visual pattern on every slide.
- Introduce a new layout only when the information type genuinely changes.
- Keep title, footer, page numbering and source-note conventions consistent.

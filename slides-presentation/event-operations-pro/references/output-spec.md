# Event Operations Pro — Output Specification

## Default deliverables
1. `01_Event_Command_Center.xlsx`
2. `02_Event_Day_Command_Sheet.docx`
3. `03_Event_Team_Brief.pptx` — optional when team briefing is useful

## Event Command Center workbook
Recommended sheets:
- 00_Dashboard
- 01_Master_Timeline
- 02_Run_Sheet
- 03_Manpower
- 04_Checklists
- 05_Suppliers
- 06_Guest_List
- 07_Contingency
- 08_Contacts
- 09_Approvals_Decisions
- 10_Incident_Log
- 11_Post_Event

Only create sheets that improve real operations.

## XLSX quality bar
- Easy to filter and update
- Consistent status values
- No unnecessary merged cells in tables
- Freeze panes where useful
- Date/time format consistent
- Duplicate checks where appropriate
- Clear separation of confirmed facts vs recommendations
- Critical issues visible without excessive decoration

## Command Sheet quality bar
- 1–2 pages when practical
- Key timeline + critical contacts + go-live checklist + top risks + escalation
- Readable on mobile and printable
- No long narrative

## PPTX quality bar
- 7–12 slides by default
- Visual and concise
- Suitable for staff/vendor briefing
- Do not paste full spreadsheets onto slides

## Integrity rules
- Never invent confirmed facts
- Use TBD / Needs Confirmation for missing critical data
- Do not mark recommendations as approved decisions
- Do not invent phone numbers, vendor names, costs, attendance or timestamps

# Deck Redesign

Improve an existing deck's clarity, hierarchy, consistency and visual quality without changing factual meaning.

## Workflow
1. Review the whole deck before editing individual slides.
2. Identify duplicated content, weak transitions, overloaded slides, inconsistent typography, poor chart choices and visual clutter.
3. Preserve all factual data unless content changes are explicitly requested.
4. Reorganize slide order when it improves the story.
5. Replace paragraphs with concise copy, diagrams, charts or structured layouts when appropriate.
6. Standardize title hierarchy, spacing, typography, chart styles and visual rhythm.
7. Flag contradictory or unsupported content.

## Principles
One dominant message per slide. Prefer fewer, stronger elements. Keep charts readable on mobile and projectors. Preserve supplied brand assets. Return a new editable PowerPoint by default.

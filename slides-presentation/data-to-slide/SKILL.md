# Data to Slide

Convert raw numbers into clear presentation evidence.

## Workflow

1. Confirm the grain of the data: period, entity, unit, currency and source.
2. Check obvious quality issues: blanks, duplicates, inconsistent units, impossible values and mismatched totals.
3. Compute only metrics supported by the source data.
4. Separate observed data from assumptions, targets and forecasts.
5. Identify the decision-relevant story: trend, variance, mix, ranking, contribution, efficiency, conversion, retention, growth or risk.
6. Choose the simplest chart that communicates the point.
7. Write a takeaway title that states what the chart means, not just what it contains.
8. Add source/period notes when ambiguity is possible.

## Chart selection

- Time trend -> line chart.
- Category comparison -> horizontal or vertical bar chart.
- Actual vs target -> bar/bullet-style comparison.
- Composition with few categories -> stacked bar or limited donut only when part-to-whole is the point.
- Contribution/waterfall logic -> waterfall when supported.
- Relationship -> scatter plot.
- Exact values across many dimensions -> table or heatmap-style matrix.

## Rules

- Never use 3D charts.
- Avoid pie/donut charts with many categories.
- Do not imply causality from correlation.
- Do not hide negative results to make a deck look better.
- Preserve significant digits sensibly and keep units consistent.
- If data is insufficient for a requested KPI, state that it cannot be calculated from the available source.

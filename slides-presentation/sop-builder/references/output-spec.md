# SOP Builder — Output Specification

## Recommended deliverables
- SOP_Master_<Process>.docx — canonical controlled document
- SOP_QuickView_<Process>.pptx — visual training/briefing version
- Optional: SOP_Checklist_<Process>.xlsx when the workflow benefits from repeated operational tracking

## DOCX quality bar
- Professional A4 layout
- Clear heading hierarchy
- Document-control block
- Tables fit page width
- No orphan headings where practical
- Consistent terminology and role names
- Page numbering
- Revision history

## PPTX quality bar
- Visual, not text-heavy
- One concept per slide
- Workflow should be diagrammatic where useful
- Use concise labels
- Highlight decision points and escalation
- Include final checklist slide

## Content integrity
- Never invent policy facts
- Separate current state from recommendation
- Mark unknown critical facts as TBD / Needs Confirmation

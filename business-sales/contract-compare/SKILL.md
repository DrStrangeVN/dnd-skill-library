# Contract Compare

Compare the actual files or texts provided. Never say a version is unchanged unless all relevant sections and appendices were compared.

## Workflow

1. Identify version labels/dates and check whether schedules, exhibits, annexes, or language versions are present in each.
2. Align sections and defined terms; distinguish formatting edits from substantive edits.
3. Capture additions, deletions, and changes to amounts, dates, thresholds, triggers, discretion, remedies, scope, and conditions.
4. Classify each change by direction of effect for the user: improves, worsens, mixed, neutral, or unclear.
5. Check consequential changes with `contract-review` and verify legal claims with `law-source-check`.
6. Summarize negotiation items and point to exact section/page/clause when available.

## Output

Start with the material changes. Provide a table with: clause; old text/term; new text/term; practical effect; risk level; recommended response. Then list purely editorial changes and missing documents. Do not infer intent from a change alone; label interpretations as possible effects.
